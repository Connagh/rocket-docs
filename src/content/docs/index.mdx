## How every page works

Every rebuilt zone follows the same flight plan, so once you have read one you know where everything is in the rest:
**intuition → analogy → diagram → equations → interactive tool → worked example → where it stops → on the drawing →
references.** Calculations run on unit-tested code, and every worked example is checked by those same tests.

<Aside type="tip" title="The one-paragraph drawing philosophy">
  A drawing is a contract, not a picture. Every dimension and note should answer one question: *how will the inspector
  accept or reject this?* If a requirement can't be measured, it can't be enforced. Dimension the function, tolerance
  only as tight as the function needs, and state the standard you're working to.
</Aside>

<Aside type="note" title="v2 is being rebuilt zone by zone">
  Zones marked **v1** in the rail open the complete original reference at that zone, so nothing is lost while the rest
  are rebuilt. The [roadmap](start/roadmap/) shows the order.
</Aside>

<Aside type="caution" title="Reference aid only">
  Values are typical industry guidance for early design and learning. Always verify against the current issue of the
  cited standard, your organisation's approved data and your programme's requirements before release.
</Aside>
