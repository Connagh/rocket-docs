## How every page works

All rebuilt zones use the same sequence. When you have read one page, you know where to find all the items on the
other pages: **intuition → analogy → diagram → equations → interactive tool → worked example → where it stops → on the
drawing → references.** The calculations use unit-tested code, and the same tests check each worked example.

<Aside type="tip" title="The drawing philosophy in one paragraph">
  A drawing is a contract, not a picture. Each dimension and note must answer one question: *how will the inspector
  accept or reject this?* If you cannot measure a requirement, you cannot enforce it. Dimension the function, make the
  tolerance only as tight as the function needs, and give the standard that applies.
</Aside>

<Aside type="note" title="v2 is rebuilt zone by zone">
  Zones with the mark **v1** in the rail open the complete original reference at that zone, so no content is lost
  while the other zones are rebuilt. The [roadmap](start/roadmap/) shows the sequence.
</Aside>

<Aside type="caution" title="Reference aid only">
  The values are typical industry guidance for early design and learning. Always verify against the current issue of
  the cited standard, the approved data of your organisation and the requirements of your programme before release.
</Aside>
