## Built for learning and for doing

<CardGrid>
  <Card title="Intuition first" icon="star">
    Every topic opens with an everyday analogy and a diagram before the first equation — a sausage in a pan for hoop
    stress, a bath with the plug out for chamber pressure.
  </Card>
  <Card title="Interactive, not static" icon="setting">
    Calculators and diagrams respond as you change the inputs, so you can see *why* the answer moves, not just that it
    does.
  </Card>
  <Card title="Checked by hand" icon="approve-check">
    Each tool comes with a worked example done step by step, and the calculation code is unit-tested against those
    same numbers.
  </Card>
  <Card title="Honest about limits" icon="warning">
    Every page says where the method stops and what experienced engineers watch for. Screening values are labelled as
    screening values.
  </Card>
</CardGrid>
