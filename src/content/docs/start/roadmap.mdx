REF·DB v1 is a single offline HTML file with 64 zones in eight phases. Each zone is rebuilt here with the same
structure: **intuition → analogy → visual → equations → interactive tool → worked example → traps → references.** Until a
zone is rebuilt, its row (and the rail) opens the original at that zone, so no content is lost.

The site makes this page from the zone plan, so the numbers and the status are always current.
