REF·DB v1 is a single offline HTML file with 64 zones across eight phases. Every zone is being rebuilt here with the same
structure: **intuition → analogy → visual → equations → interactive tool → worked example → traps → references.** Until a
zone is rebuilt, its row (and the rail) opens the original at that zone, so nothing is lost on the way.

This page is generated from the zone plan, so numbers and status can never go stale.
