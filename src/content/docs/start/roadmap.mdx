REF·DB v1 is a single offline HTML file with 64 topics in eight phases. Each topic is rebuilt here with the same
structure: **intuition → analogy → visual → equations → interactive tool → worked example → traps → references.** Until a
topic is rebuilt, its row (and its entry in the menu) opens the original at that topic, so no content is lost.

The site makes this page from the zone plan, so the numbers and the status are always current.
