description: How the 64 zones of REF·DB v1 are being rebuilt as learning-first topic pages, and in what order.

REF·DB v1 is a single offline HTML file with 64 "zones". Every zone is being rebuilt here as a topic page with the same
structure: **intuition → analogy → visual → equations → interactive tool → worked example → traps → references**.
Until a zone is rebuilt, the original is still available in full at the [legacy reference](../../legacy/).

**Status key:** ✅ rebuilt · 🔨 in progress · ⏳ legacy only
